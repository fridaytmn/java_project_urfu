***Forbes Billionaires Project***

Проект загружает данные о миллиардерaх из CSV-файла, сохраняет их в базу данных SQLite, выполняет SQL-запросы и визуализирует результаты с помощью диаграммы.

Последовательность работы программы
  - **Загрузка CSV-файла.** Программа считывает данные о миллиардерах из CSV-файла.
  - **Парсинг данных.** CSV-файл преобразуется в список объектов Billionaire.
  - **Сохранение в базу данных.** Создаётся база данных SQLite, в которую сохраняются все объекты.
  - **SQL-запросы.** Выполняются запросы к базе данных (поиск самого молодого миллиардера, анализ по странам и индустриям).
  - **Вывод результатов.** Результаты запросов выводятся в консоль.
  - **Визуализация данных.** Числовые данные отображаются в виде диаграмм с использованием JFreeChart.
